# sape-mcp

MCP-сервер ([Model Context Protocol](https://modelcontextprotocol.io)) для работы с [sape.ru](https://www.sape.ru) через XML-RPC API. Позволяет любому MCP-совместимому LLM-боту (Claude Desktop, Hermes, Cursor и др.) читать список проектов, смотреть ссылки и бюджеты, искать площадки по заданию и докупать ссылки.

## Возможности

- чтение баланса, информации об аккаунте и расходах;
- список проектов и параметров каждого проекта;
- URL-ы проектов, анкоры, размещённые ссылки и их статусы;
- поиск страниц площадок по фильтрам (тема, цена, тИЦ/PR и др.) — «задание» на покупку;
- покупка ссылки (одиночная и пакетная) с ограничением максимальной цены;
- универсальный вызов любого метода [XML-RPC API sape.ru](https://api.sape.ru/xmlrpc/) (`sape_call`).

Встроен rate-limiter: не более 115 запросов/мин (лимит sape.ru — 120), автоматическая авторизация по токену и повторный login при разрыве сессии.

## Установка

```bash
pip install .
```

## Получение токена

1. Зайдите на https://passport.sape.ru/security/token/ под своим аккаунтом.
2. Сгенерируйте API-токен.

## Конфигурация (переменные окружения)

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `SAPE_LOGIN` | да | — | логин sape.ru |
| `SAPE_TOKEN` | да | — | API-токен |
| `SAPE_API_URL` | нет | `https://api.sape.ru/xmlrpc/` | адрес API |
| `SAPE_MAX_CALLS_PER_MINUTE` | нет | `115` | троттлинг запросов |

## Подключение к клиенту

### Claude Desktop / любой MCP-клиент (stdio)

```json
{
  "mcpServers": {
    "sape": {
      "command": "sape-mcp",
      "env": {
        "SAPE_LOGIN": "ваш_логин",
        "SAPE_TOKEN": "ваш_токен"
      }
    }
  }
}
```

### Hermes Agent

Добавьте в конфигурацию MCP-серверов:

```yaml
mcp:
  servers:
    sape:
      command: sape-mcp
      env:
        SAPE_LOGIN: ваш_логин
        SAPE_TOKEN: ваш_токен
```

## Инструменты

| Инструмент | Назначение |
|---|---|
| `get_balance` | баланс (полный и доступный) |
| `get_user` | аккаунт, расходы за сутки/неделю, бюджет |
| `list_projects` | список проектов с числом урлов/ссылок |
| `get_project` | параметры проекта и расходы |
| `list_urls` | URL-ы проекта |
| `get_url_anchors` | анкоры URL-а и лимиты использования |
| `get_project_links` | все ссылки проекта со статусами |
| `get_url_links` | ссылки конкретного URL-а |
| `search_pages` | поиск площадок/страниц по фильтрам (задание на покупку) |
| `create_placement` | покупка ссылки (⚠️ тратит деньги; есть max_price) |
| `create_placements` | пакетная покупка (до 200 за вызов) |
| `sape_call` | универсальный вызов любого метода API |

## Пример сценария для бота

> «Покажи мои проекты. Для проекта X найди до 20 площадок по теме "ремонт" не дороже 50 руб. и докупи по 1 ссылке, но не трать больше 500 руб. за всё»

Бот: `list_projects` → `list_urls` → `search_pages` (фильтр по теме/цене) → `create_placements` с `max_price`.

## Безопасность

- Токен хранится только в переменных окружения вашего MCP-клиента, не пишется в логи.
- Покупка ссылок расходует реальные средства: используйте `max_price` для ограничения цены, а бюджет — инструмент `get_balance`.
- API sape.ru ограничен 120 запросами/мин на аккаунт; сервер троттлит на 115.
